# 클릭클릭해 (ClickClickHea) 소프트웨어 제품 명세서

본 문서는 자동 마우스 클릭 제어 및 업무 지원 유틸리티 프로그램인 **클릭클릭해 (ClickClickHea)**의 기능 구성, 기술 아키텍처, 환경 요구사항 및 빌드 절차를 규정합니다.

---

## 1. 개요 (Overview)

본 프로그램은 사용자가 사전 지정한 복수의 디스플레이 좌표를 기준으로 주기적인 마우스 클릭 작업을 자동 수행하는 GUI 기반 매크로 애플리케이션입니다. 업무 화면 보호기 전환 방지 및 단순 반복 데이터 입력 작업을 지원하기 위해 설계되었으며, 다국어 환경과 다양한 작업 공간에 맞춘 테마 모드를 제공합니다.

---

## 2. 주요 기능 규격 (Key Specifications)

### 2.1. 좌표 및 액션 제어
- **다중 좌표 등록**: 최대 5개 지점의 독립된 화면 좌표(X, Y) 캡처 및 등록.
- **마우스 버튼 구분**: 전역 입력 감지를 통한 마우스 좌클릭(Left) 및 우클릭(Right) 분기 실행.
- **개별 실행 간격 설정**: 각 좌표별 지연 대기 시간(분/초 단위) 개별 입력 및 테이블 행 더블클릭을 통한 수정 지원.

### 2.2. 제어 옵션 및 안티 디텍션
- **커서 이동 애니메이션**: 기계적인 순간이동 대신 부드러운 좌표 이동 궤적을 활성화/비활성화하는 옵션 제공.
- **무작위 지연(Random Delay)**: 설정된 인터벌 시간 기준 0%~50% 범위 내 난수 편차를 부여하여 일정한 패턴 감지를 방지.

### 2.3. 타이머 및 진행률 시각화
- **정밀 카운트다운 타이머**: 최대 24시간 범위 내 초 단위 설정 지원 (기본값: 10시간).
- **모던 바 게이지**: 잔여 실행 시간에 따른 실시간 프로그레스 바(Canvas 기반) 시각화.
- **3단계 상태 제어**:
  - 시작(Start): 매크로 루프 및 타이머 동시 개시/재개.
  - 일시정지(Pause): 현재 진행 단계 및 타이머 카운트다운 일시 동결.
  - 정지(Stop): 매크로 엔진 즉시 중단 및 타이머를 초기 설정 시간으로 리셋.

### 2.4. 사용자 환경 (UI / UX)
- **3종 전용 테마**:
  - Excel 모드: 구글 스프레드시트 수식 바(`fx`) 형태의 헤더 및 데이터 그리드 스타일.
  - Terminal 모드: PowerShell 및 CMD 콘솔 기반의 다크 모드 및 일체형 텍스트 스타일.
  - Kids 모드: 소프트 파스텔 톤 기반 카드 레이아웃.
- **다국어 지원(i18n)**: 한국어(KO), 영어(EN), 중국어(ZH), 스페인어(ES) 실시간 언어 전환.
- **모니터링 및 메모**:
  - 실시간 이벤트 로그 콘솔 (스크롤바 내장).
  - 임시 메모장: 작성 데이터는 `mouse_config.json`에 실시간 비동기 직렬화되어 프로그램 재시작 시 자동 복원.

### 2.5. 전역 단축키 (Shortcut Keys)
- `F1`: 프로그램 버전 정보 및 단축키 안내 다이얼로그 호출.
- `F2`: 마우스 좌표 캡처 리스너 시작.
- `F5`: 매크로 실행 / 일시정지 토글.
- `ESC`: 프로그램 안전 종료 및 설정 파일 저장.

## 3. 시스템 아키텍처 및 디렉터리 구조

```text
clickclick_hea/
│
├── app/
│   ├── __init__.py         # 패키지 네임스페이스 및 공개 인터페이스 정의
│   ├── app.py              # 메인 애플리케이션 프레임워크 및 이벤트 핸들러
│   ├── main.py             # 하위 모듈 진입점
│   │
│   ├── ui/
│   │   ├── __init__.py
│   │   ├── styles.py       # 테마별 색상 팔레트 및 위젯 스타일 정의
│   │   ├── layout.py       # 컴포넌트 배치 및 계층 구조 설계
│   │   └── dialogs.py      # 테마 종속 모달 창 및 간격 설정 대화상자
│   │
│   ├── core/
│   │   ├── __init__.py
│   │   ├── macro.py        # 마우스 입력 제어 및 다중 스레드 매크로 엔진
│   │   ├── capture.py      # 전역 마우스 이벤트 리스너 (pynput)
│   │   └── timer.py        # 카운트다운 및 타임아웃 이벤트 관리자
│   │
│   └── utils/
│       ├── __init__.py
│       ├── config.py       # JSON 기반 환경설정 입출력 처리기
│       ├── logger.py       # UI 텍스트 위젯 로그 출력 어댑터
│       ├── i18n.py         # 다국어 리소스 사전 및 번역 매니저
│       └── resource.py     # 실행 환경별 절대 리소스 경로 해석기
│
├── assets/
│   ├── generate_icon.py    # 표준 ICO 포맷 리소스 생성 유틸리티
│   └── mouse.ico           # 윈도우 및 프로세스 표준 아이콘
│
├── run.py                  # 최상위 실행 진입점 (빌드 타깃)
├── mouse_config.json       # 사용자 데이터 지속성 스토리지 (자동 생성)
├── requirements.txt        # 외부 라이브러리 종속성 명세
├── .gitignore              # 버전 관리 제외 대상 명세
└── README.md               # 제품 기술 문서
```

## 4. 환경 요구사항 및 설치

- 지원 운영체제: Microsoft Windows 10 이상 (64-bit 권장)

- 런타임 환경: Python 3.8 이상

### 4.1. 의존성 패키지 설치

```
pip install -r requirements.txt
```

### 4.2. 애플리케이션 실행
```
python run.py
```

## 5. 실행 파일(EXE) 배포 빌드

- Python 인터프리터 및 종속 라이브러리가 설치되지 않은 환경에서 독립 실행이 가능하도록 PyInstaller를 이용해 단일 바이너리로 컴파일합니다.


### 5.1. Build

```
pyinstaller --noconsole --onefile --icon="assets/mouse.ico" --add-data "assets;assets" run.py -n "click_x2" --clean
```

### 5.2. 이전 Build 기록 삭제
```
Remove-Item -Recurse -Force build, dist -ErrorAction SilentlyContinue  
```
